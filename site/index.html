PUBLIC RECORDS · US ONLY · OFFLINE WHERE POSSIBLE

One name in.
A sourced dossier out.

govint searches 20 US government databases for a company or person, links what it finds into one entity graph, and writes a markdown brief where every line cites its source record.

$ govint brief "Palantir Technologies" -o palantir.md

03 Commands

brief NAME
Markdown dossier with flags and citations.
pivot NAME
Linked graph across all sources, exportable as DOT or JSON.
screen NAME | --csv
Sanctions and export-control screening, one name or a whole file.
congress flags
House stock trades ranked by committee overlap, late filing, size and contract spikes.
near ADDRESS
Representatives, EPA violators, local federal contracts, aircraft operators, quakes.
lobby NAME
Lobbying spend, firms, issues, and ex-officials lobbying for a client.
shells NAME | ADDRESS
Who else is registered at the same address, with mail drops marked.
ppp --flagged
PPP loans that the reported jobs can't explain, and charge-offs.
offshore NAME
ICIJ Offshore Leaks entities and their links.
grep "PHRASE"
Full-text search over every SEC filing.
sky now ADDRESS
Aircraft overhead, with registered owners, from OpenSky or your own receiver.
watch add … / run
Watchlists for companies, tails, phrases, lobbying and dockets, with ntfy alerts.

Also: edgar, spend, fec, lei, tail, sam, fara, court and leaks. Add --json before any command to get machine-readable output.

04 Install

Needs Python and uv. Most sources work with no keys.

# install
git clone https://github.com/NPCmillionaire/govint
uv tool install --editable ./govint

# SEC requires a contact in the User-Agent
govint config contact you@example.com

# optional keys
govint config data_gov_key <key>      # api.data.gov/signup
govint config sam_key <key>           # sam.gov > Account Details

# offline datasets
govint sync csl                       # sanctions, ~30 MB
govint sync faa                       # aircraft registry
govint sync offshore                  # ICIJ, ~750 MB on disk
govint status

05 Read before relying on it

Names are matched fuzzily and scored from 0 to 100. Screening hits at 95 or above are flagged as matches, and hits from 88 to 95 as possible matches. Appearing in a dataset doesn't imply wrongdoing, and a person who shares a name with a record is often someone else. Every line links to its source, so check it there.
